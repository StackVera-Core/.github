# StackVera-Core/.github

Organization-wide default community files for all repositories in `StackVera-Core`.

| Path | Purpose |
| --- | --- |
| `pull_request_template.md` | Default PR template for every repo that does not define its own |
| `SECURITY.md` | How to report a vulnerability, shown on every repo's Security tab |

## Important

- This repository is **public**. GitHub only applies organization-wide default files from a public `.github` repository.
- It contains templates only. No workflows, secrets, account IDs, role names or internal hostnames.
- Reusable CI workflows live in the private repo `platform-workflows`.
- `CODEOWNERS` cannot be set organization-wide. Every repository keeps its own `CODEOWNERS` file.
