# Security Policy

## Reporting a vulnerability

Please report security issues privately to **[security@stackvera.io]**. Do not open a public issue.

Include what you found, how to reproduce it and which product or repository is affected. We confirm receipt within 2 business days and keep you informed until the issue is resolved.

## Scope

All repositories in the `StackVera-Core` GitHub organization and the services running under `stackvera.io`.
